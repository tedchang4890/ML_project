# iM뱅크 수도권 진출을 위한 기업 상장폐지 예측 및 최적 입지 도출

> 기간 : **2026.04.13. ~ 2026.04.23.**

# 1. Tech Stack & Tools
### **Language & Environment**
- **Python** : 데이터 전처리, 머신러닝 모델 구축 및 공간 최적화 알고리즘 수행의 메인 언어
### **Data Analysis & Manipulation**
- **Pandas & NumPy** : 상장/비상장 재무 데이터셋 병합, 거시경제 지표 통합 및 대규모 파생변수 엔지니어링
- **Matplotlib & Seaborn & Folium** : 피처 중요도 파악, 임계값 최적화 시각화 및 MCLP 알고리즘 기반 입지 후보군 지도 맵핑 시각화
### **Machine Learning & Optimization**
- **XGBoost / LightGBM / CatBoost / RandomForest / ExtraTrees** : 고성능 트리 및 부스팅 알고리즘들을 전방 모델(Base Models)로 사용하여 예측력 강화
- **Scikit-learn** : **StackingClassifier**를 활용한 앙상블 모델 구현, **LogisticRegression**을 통한 메타 모델링, 성능 평가 지표(**F1-score, Accuracy, ROC-AUC**) 산출 및 **RobustScaler**를 통한 피처 스케일링
- **Optuna** : 전방 부스팅 모델의 하이퍼파라미터 탐색(100회) 및 메타 모델 튜닝(30회)을 통한 최적의 예측 조합 도출
- **SciPy (milp)** : 제약 조건이 포함된 최대 커버링 입지 문제(MCLP, Maximal Covering Location Problem) 해결을 위한 혼합 정수 선형 계획법 알고리즘 적용

### EDA 해석
- **영업점 밀집도 현황** : 현재 iM뱅크 전체 영업점의 약 80%가 대구·경북 지역에 집중되어 있음. -> **시중은행 전환 이후 인구 통계 중심이 아닌 우량 법인 밀집도를 기반으로 한 정교한 수도권 진출 요충지 선점이 필수적임**
- **수도권 기업 금융 특성** : 수도권 영업점의 창구 거래 건수는 1천여 건 안팎으로 적은 편이나, 거래 금액 규모는 압도적으로 큼. -> **기업 금융의 특수성을 고려하여, 건수보다 단일 수익 규모가 큰 수도권 우량 법인을 타겟팅해야 함을 시사**
- **잠재적 수익성 포착** : 소상공인과 중소기업의 분포도 역시 서울과 경기 지역에 가장 높은 비중으로 형성되어 있음. -> **수도권 내 잠재적 금융 수요가 매우 풍부하며, MCLP 알고리즘 적용 지역을 중심으로 신규 점포를 확대해야 함**

# 3. Data Source
  * **기업 재무제표 데이터**: 금융위원회 Open DART API를 활용한 2015~2024년 결산 기준 코스닥 전 업종 기업 데이터
  * **거시경제 데이터**: KOSIS, 미디어통계포털, e-나라지표를 활용하여 수집한 경제심리지수, 전산업생산지수, 실업률, 원/달러 환율 등 총 13개 지표

# 4. Data Processing

### Feature Selection & Data Cleaning
  * **결측치 및 이상치 처리** : Open DART API 수집 과정에서 누락된 유동자산 등 399개의 결측치는 결산년도 재무상태표를 1:1 기입하여 복원하였으며, 금융업 등 특수 업종의 결측치는 모델 무결성을 위해 삭제 처리
  * **불필요한 식별자 제거** : 예측에 유의미한 정보를 제공하지 않는 회사명, 종목코드, 상장일, 주소 등 22개 컬럼을 일괄 삭제하여 모델 복잡도 축소
  * **최종 병합 데이터셋** : 전처리가 완료된 1,221개 기업 재무지표 데이터셋

### Metric Design (파생변수 생성)
  * 절대적인 자산/부채 규모의 차이로 인한 왜곡을 방지하기 위해 원본 재무 데이터를 상태 파악용 상대적 비율로 변환
  * **안정성 및 유동성** : 기존 데이터 외에 **이익안정성, 부채상환능력, 자산효율성, 단기위험도** 변수를 추가로 도출

### Encoding & Feature Scaling
  * **Label Encoding** : 자본잠식구분, 상장폐지구분 등 범주형 문자열 변수를 수치화하여 머신러닝 연산 구조에 적합하게 변환
  * **Scaling** : **RobustScaler**를 적용하여 대규모 기업 재무 지표에 분포하는 극단적인 이상치들의 영향을 최소화
  * **최종 활용 변수** : 분석 활용 피처 총 44개 (거시경제 13개, 재무지표 31개)

# 5. ML

## AutoML & Hyperparameter Tuning
- **Target Objective** : 파이캐럿(PyCaret) 검증 및 Optuna 프레임워크를 활용한 **F1-Score** 극대화
- **Search Space** : n_estimators, max_depth, learning_rate, scale_pos_weight 등 불균형 데이터에 대응하기 위한 부스팅 앙상블의 핵심 파라미터 최적화(100회 시도)
- **Target Models** : 검증 과정에서 최고 성능을 달성한 5대장 모델 (**XGBoost, LightGBM, CatBoost, Random Forest, Extra Trees**)

## Stacking Pipe
- **Base Models** : 파라미터 최적화 튜닝이 개별적으로 완료된 5종의 고성능 트리 및 부스팅 모델
- **Meta Model** : 베이스 모델의 복잡한 비선형 예측값을 최종 결합하고 과적합(Overfitting)을 제어하기 위해 **Logistic Regression** (C=1.1025 / 5.8807 튜닝)을 메타 모델로 채택

| **F1 Score** | 0.8718 |
| **ROC-AUC** | 0.9125 |

### SHAP value 해석
- **거시경제 지표의 영향력** : SHAP 중요도 상위 10개 중 **전산업생산지수, gdp, 소비자물가지수, 원/달러 환율, 경제심리지수** 등 거시경제 변수들이 최상위권을 휩쓸었음. -> **개별 기업의 재무 상태뿐만 아니라 외부 경기 흐름 및 물가 환경이 기업 생존(상장 유지)에 결정적인 영향을 미침을 확인**
- **자기자본이익률(ROE) & 자산효율성** : 재무 지표 중에서는 ROE, ROA, 자산효율성, 매출액 등 수익성 지표의 기여도가 높게 나타남.
- **유동부채의존도 & 단기위험도** : 일부 부채 관련 변수는 값의 크기에 따라 예측에 미치는 방향이 엇갈리는 비선형적·양방향 영향을 보여주어, 의존도가 일정 수준 이상으로 과도해지면 이탈(상장폐지) 확률이 급등하는 구조임.

# 7. MCLP 기반 최적 입지 도출

### 수요 점수 산출 및 제약 조건 설정
- **수요 점수(MCLP SCORE)** : SHAP 분석을 통해 입증된 13개 거시경제 변수와 31개 재무지표 변수를 각각 Min-Max 스케일링으로 정규화한 후, `(거시경제 평균 + 재무지표 평균) / 2`의 산식을 적용하여 질적 가치가 반영된 기업별 수요 점수를 산정함.
- **커버리지 반경 최적화** : 5km, 6km, 7km 반경을 비교 시뮬레이션한 결과, 기업 커버 수용 한계와 영업점 간 상호 잠식 문제를 균형적으로 방어할 수 있는 반경 **6km**를 최종 기준으로 확정함.
- **MCLP 최적화 과정** : 기존 영업점이 이미 커버 중인 6km 반경 내 수요를 필터링하여 중복 투자를 방지하고, 혼합 정수 선형 계획법(MILP)을 이용해 한정된 10개의 점포로 '총 수요 점수(가중치)'를 최대화하는 위치를 탐색함.

# 8. 최종 결론 및 전략 제안

- **수도권 고부가가치 시장 선점** : 단순한 영업점 수 늘리기가 아닌, 객단가 및 금융 거래 볼륨이 큰 수도권의 고부가가치 우량 기업 밀집 지역에 거점을 마련하여 효율적인 수익 창출 도모
- **위험-수요 동시 고려의 과학적 의사결정** : 상장폐지 예측 머신러닝으로 부실 위험 기업을 필터링하고, MCLP 알고리즘을 통해 우량 기업 커버리지를 극대화한 전략적 요충지(분당, 호계, 송도 등)를 발굴함.
- **PRM(기업영업전문역) 중심 공략** : 새롭게 도출된 수도권 Top 5 커버리지 핵심 지역을 중심으로 본부급 PRM 조직을 밀착 투입하여, 전통적인 창구 영업 대비 약 3배 높은 대출 효율성을 달성하는 수도권 기업 금융 성공 모델 안착 제안
